![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

A customized, modern, and interactive link page to centralize all my social media and projects. Designed with a neon 3D design, smooth animations, and a dark/light theme.

## 🔗 Live Demo
👉 **[Visit the page](https://bstudio136.github.io/mylink/)**

## ✨ Features

- **Neon & 3D Design**: Golden and purple light effects, cards with 3D tilt on hover, and click animations.
- **Dark/Light Theme**: Toggle between modes with a dedicated button. The choice is saved in the browser's `localStorage`.
- **Projects Section (Accordion)**: An animated dropdown menu to showcase my different projects (like BSuite).
- **Social Media Grid**: Links to GitHub, TikTok, Twitter/X, Facebook, Instagram, and YouTube with brand icons.
- **Email Copy**: An interactive button to copy my email address to the clipboard in one click.
- **100% Responsive**: Adapts perfectly to mobile, tablet, and desktop screens.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: CSS Variables, Flexbox, CSS Grid, Animations (`@keyframes`), 3D effects (`transform: perspective`), `clip-path` for shapes.
- **JavaScript (Vanilla)**: Theme management, click animations, accordion, clipboard copy, and 3D motion effects.
- **Font Awesome**: For all icons (social media, projects, email).

## 🚀 Installation & Usage

This project is a simple static file. To run it locally:

1. Clone the repository:
   git clone https://github.com/Bstudio136/mylink.git
2. Open the `index.html` file in your browser.
3. That's it! No dependencies or build necessary.

## 🎨 Customization

To adapt this page to your own profile:

1. **Avatar**: Modify the image URL in the `<img>` tag (around line ~300).
2. **Links**: Update the social media and project URLs in the `<a>` tags.
3. **Email**: Replace `"email@exemple.com"` with your real address in the `copyEmail()` function at the bottom of the HTML file.
4. **Colors**: Modify the CSS variables in `:root` to change the theme colors (e.g., `--card-border: #FFD700` for gold).

Une page de liens personnalisée, moderne et interactive pour centraliser tous mes réseaux sociaux et projets. Conçue avec un design néon 3D, des animations fluides et un thème sombre/clair.

## 🔗 Démo en direct
👉 **[Visiter la page](https://bstudio136.github.io/mylink/)**

## ✨ Fonctionnalités

- **Design Néon & 3D** : Effets de lumière dorée et violette, cartes avec inclinaison 3D au survol et animations de clic.
- **Thème Sombre/Clair** : Basculez entre les modes avec un bouton dédié. Le choix est sauvegardé dans le `localStorage` du navigateur.
- **Section Projets (Accordéon)** : Un menu déroulant animé pour présenter mes différents projets (comme BSuite).
- **Grille de Réseaux Sociaux** : Liens vers GitHub, TikTok, Twitter/X, Facebook, Instagram et YouTube avec icônes de marque.
- **Copie d'Email** : Un bouton interactif pour copier mon adresse email dans le presse-papiers en un clic.
- **100% Responsive** : S'adapte parfaitement aux mobiles, tablettes et ordinateurs.

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique.
- **CSS3** : Variables CSS, Flexbox, CSS Grid, Animations (`@keyframes`), effets 3D (`transform: perspective`), `clip-path` pour les formes.
- **JavaScript (Vanilla)** : Gestion du thème, animations de clic, accordéon, copie dans le presse-papiers, et effets de mouvement 3D.
- **Font Awesome** : Pour toutes les icônes (réseaux sociaux, projets, email).

## 🚀 Installation & Utilisation

Ce projet est un simple fichier statique. Pour le faire fonctionner localement :

1. Clonez le dépôt :
   git clone https://github.com/Bstudio136/mylink.git
2. Ouvrez le fichier `index.html` dans votre navigateur.
3. C'est tout ! Aucune dépendance ou build n'est nécessaire.

## 🎨 Personnalisation

Pour adapter cette page à votre propre profil :

1. **Avatar** : Modifiez l'URL de l'image dans la balise `<img>` (ligne ~300).
2. **Liens** : Mettez à jour les URLs des réseaux sociaux et des projets dans les balises `<a>`.
3. **Email** : Remplacez `"email@exemple.com"` par votre véritable adresse dans la fonction `copyEmail()` en bas du fichier HTML.
4. **Couleurs** : Modifiez les variables CSS dans `:root` pour changer les couleurs du thème (par exemple, `--card-border: #FFD700` pour l'or).
