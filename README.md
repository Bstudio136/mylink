Une page de liens personnalisée, moderne et interactive pour centraliser tous mes réseaux sociaux et projets. Conçue avec un design néon 3D, des animations fluides et un thème sombre/clair.

## 🔗 Démo en direct
👉 **[Visiter la page](https://bstudio136.github.io/mylink/)**

## ✨ Fonctionnalités

- **Design Néon & 3D** : Effets de lumière dorée et violette, cartes avec inclinaison 3D au survol et animations de clic.
- **Thème Sombre/Clair** : Basculez entre les modes avec un bouton dédié. Le choix est sauvegardé dans le `localStorage` du navigateur.
- **Section Projets (Accordéon)** : Un menu déroulant animé pour présenter mes différents projets (comme BSuite).
- **Grille de Réseaux Sociaux** : Liens vers GitHub, TikTok, Twitter/X, Facebook, Instagram et YouTube avec icônes de marque.
- **Copie d'Email** : Un bouton interactif pour copier mon adresse email dans le presse-papiers en un clic.
- **100% Responsive** : S'adapte parfaitement aux mobiles, tablettes et ordinateurs.

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique.
- **CSS3** : Variables CSS, Flexbox, CSS Grid, Animations (`@keyframes`), effets 3D (`transform: perspective`), `clip-path` pour les formes.
- **JavaScript (Vanilla)** : Gestion du thème, animations de clic, accordéon, copie dans le presse-papiers, et effets de mouvement 3D.
- **Font Awesome** : Pour toutes les icônes (réseaux sociaux, projets, email).

## 🚀 Installation & Utilisation

Ce projet est un simple fichier statique. Pour le faire fonctionner localement :

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/Bstudio136/mylink.git

2. Ouvrez le fichier index.html dans votre navigateur.
3. C'est tout ! Aucune dépendance ou build n'est nécessaire.

🎨 Personnalisation

Pour adapter cette page à votre propre profil :

1. Avatar : Modifiez l'URL de l'image dans la balise <img> (ligne ~300).
2. Liens : Mettez à jour les URLs des réseaux sociaux et des projets dans les balises <a>.
3. Email : Remplacez "email@exemple.com" par votre véritable adresse dans la fonction copyEmail() en bas du fichier HTML.
4. Couleurs : Modifiez les variables CSS dans :root pour changer les couleurs du thème (par exemple, --card-border: #FFD700 pour l'or).
